# 🧭 智能导航系统

一个基于 OpenStreetMap 的开源导航应用，支持地图浏览、地点搜索、路线规划和实时定位。

## ✨ 功能特性

- 🗺️ **地图浏览**：可缩放、可拖动的交互式地图
- 🔍 **地点搜索**：支持地址和地名搜索
- 🚗 **路线规划**：支持驾车、步行、骑行三种出行方式
- 📍 **实时定位**：获取并显示当前位置
- 📊 **路线信息**：显示预计距离和所需时间
- 🎯 **地图选点**：可直接在地图上点击选择起点和终点
- 🌐 **响应式设计**：支持桌面和移动设备
- 🔄 **错误处理**：完善的错误提示和网络超时处理

## 🚀 快速开始

### 直接运行

1. 在浏览器中打开 `index.html` 文件即可使用
2. 无需安装任何依赖或构建工具
3. 建议使用现代浏览器（Chrome、Firefox、Edge、Safari）

### 本地服务器运行（推荐）

为了获得更好的体验和避免 CORS 问题，建议使用本地服务器：

```bash
# 使用 Python 3
python -m http.server 8000

# 或使用 Python 2
python -m SimpleHTTPServer 8000

# 或使用 Node.js (需要先安装 http-server)
npx http-server -p 8000
```

然后在浏览器中访问 `http://localhost:8000`

## 📖 使用说明

### 基本操作

1. **设置起点**
   - 在"起点"输入框输入地址后按回车
   - 或点击"📍"按钮使用当前位置
   - 或在地图上点击选择

2. **设置终点**
   - 在"终点"输入框输入地址后按回车
   - 或在地图上点击选择

3. **选择出行方式**
   - 🚗 驾车（默认）
   - 🚶 步行
   - 🚴 骑行

4. **规划路线**
   - 点击"🔍 搜索路线"按钮
   - 查看路线信息（距离、时间）

5. **清空重新规划**
   - 点击"🗑️ 清空"按钮

### 地图操作

- **缩放**：鼠标滚轮或双击地图
- **拖动**：按住鼠标左键拖动
- **标记**：点击地图上的标记查看详细信息

## 🔧 技术架构

### 核心技术栈

- **前端**: HTML5 + CSS3 + 原生 JavaScript
- **地图库**: Leaflet.js 1.9.4
- **地图数据**: OpenStreetMap

### 服务架构

```
├── mapService.js      # 地图服务（显示、标记、路线绘制）
├── searchService.js   # 搜索服务（地点搜索、地理编码、定位）
├── routeService.js    # 路线服务（路线规划、距离计算）
├── config.js          # 配置管理
└── app.js            # 主应用逻辑
```

### 使用的免费服务

1. **OpenStreetMap**: 地图瓦片数据
   - 开源、免费
   - 无需 API 密钥

2. **Nominatim**: 地点搜索和地理编码
   - OpenStreetMap 官方搜索服务
   - 免费，需遵守使用政策

3. **OSRM**: 路线规划
   - 开源路由服务
   - 免费公共服务器

## ⚙️ 配置说明

### 环境变量（可选）

如果需要使用备用服务或自定义配置：

1. 复制 `.env.example` 为 `.env`
2. 填入相应的配置项

```bash
cp .env.example .env
```

### 服务替换

所有服务都已模块化，可以轻松替换：

- **路线服务**: 可切换到 OpenRouteService 或其他服务
- **搜索服务**: 可切换到 Google Maps API 或其他服务
- **地图瓦片**: 可切换到 Mapbox 或其他提供商

修改 `js/config.js` 中的相应配置即可。

## 🛠️ 故障排除

### 定位功能不可用

**原因**: 浏览器安全策略要求 HTTPS 或 localhost

**解决方案**:
- 使用本地服务器 (localhost)
- 或部署到 HTTPS 网站

### 搜索或路线规划失败

**可能原因**:
1. 网络连接问题
2. 服务器暂时不可用
3. 请求超时

**解决方案**:
- 检查网络连接
- 稍后重试
- 查看浏览器控制台的错误信息

### 地图不显示

**可能原因**:
1. 网络问题无法加载瓦片
2. 浏览器兼容性问题

**解决方案**:
- 检查网络连接
- 尝试其他浏览器
- 检查控制台错误信息
