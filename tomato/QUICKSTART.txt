🚀 启动方法

方法 1: 一键启动 (推荐)
  Windows:  双击 start.bat
  Mac/Linux:  ./start.sh

方法 2: 命令行启动
  python -m http.server 8000
  
  然后在浏览器访问: http://localhost:8000

✨ 主要功能

  ✅ 地图浏览 (缩放、拖动)
  ✅ 地点搜索 (支持中文)
  ✅ 路线规划 (驾车/步行/骑行)
  ✅ 实时定位
  ✅ 距离和时间显示
  ✅ 地图点选起点终点
  ✅ 完善的错误处理
  ✅ 响应式布局

⚙️ 技术架构

  前端: HTML5 + CSS3 + JavaScript
  地图: Leaflet.js + OpenStreetMap
  搜索: Nominatim (OSM)
  路线: OSRM
  定位: Geolocation API

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

💡 使用提示

  • 搜索时包含城市名提高准确度 (如 "北京 天安门")
  • 可直接在地图上点击选择起点终点
  • 按回车键快速搜索
  • 定位需要 HTTPS 或 localhost
  • 使用本地服务器获得最佳体验
