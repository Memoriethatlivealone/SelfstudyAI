🚀 快速开始

启动服务器

双击 start.bat (Windows) 或运行 ./start.sh (Linux/Mac)，或使用命令：python -m http.server 8000

打开应用

在浏览器中访问 http://localhost:8000

输入起点

在"起点"输入框输入地址，或点击📍按钮使用当前位置，或在地图上点击选择

输入终点

在"终点"输入框输入地址，或在地图上点击选择

选择出行方式

选择驾车🚗、步行🚶或骑行🚴

搜索路线

点击"🔍 搜索路线"按钮，查看路线和详细信息

💡 使用技巧

提示：

  • 搜索时包含城市名称可以提高准确性（如"北京 天安门"）
  • 可以直接在地图上点击设置起点和终点
  • 按回车键可以快速触发搜索
  • 点击地图标记可以查看详细信息
  • 使用鼠标滚轮缩放地图，拖动可以平移
  • 定位功能需要在 HTTPS 或 localhost 下使用

⚠️ 注意事项

  • 建议使用本地服务器运行，避免直接双击打开 HTML

  • 生产环境建议自建服务器或使用商业 API
