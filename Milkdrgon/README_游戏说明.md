# 🐉 奶龙大战僵尸 - 游戏说明

一个有趣的回合制战斗游戏，使用Python编写，支持Windows/Mac/Linux。

## 🎮 游戏特色

- **完整的战斗系统**：HP、能量、多种攻击方式
- **7波挑战**：从普通僵尸到最终BOSS
- **策略性玩法**：需要管理能量和生命值
- **彩色终端界面**：生动的游戏画面
- **详细统计**：记录你的战斗数据

## 📋 系统要求

- Python 3.6 或更高版本
- 支持ANSI颜色的终端（大多数现代终端都支持）

## 🚀 如何运行

### 方法1：直接运行（推荐）

```bash
python milkdragon_game.py
```

或者（如果有Python 3）：

```bash
python3 milkdragon_game.py
```

### 方法2：设置为可执行文件

**在Mac/Linux上：**
```bash
chmod +x milkdragon_game.py
./milkdragon_game.py
```

**在Windows上：**
直接双击 `milkdragon_game.py` 文件

## 🎯 游戏玩法

### 角色属性

**🐉 奶龙（你）**
- 生命值：100 HP
- 能量：100点（每回合恢复10点）
- 普通攻击：15-25伤害
- 奶息喷射：40-60伤害（消耗20能量）

### 敌人类型

- **🧟 普通僵尸**（第1-3波）：30 HP，攻击5-10
- **🧟‍♂️ 强壮僵尸**（第4-6波）：60 HP，攻击10-15  
- **👹 僵尸王**（第7波BOSS）：150 HP，攻击15-25

### 战斗选项

每回合你可以选择：

1. **普通攻击** - 造成15-25伤害，无消耗
2. **奶息喷射** - 消耗20能量，造成40-60伤害（强力技能！）
3. **喝奶恢复** - 恢复30 HP，但会被僵尸攻击
4. **尝试逃跑** - 50%概率逃离当前波次

### 游戏提示

✨ **策略建议：**
- 对付普通僵尸用普通攻击节省能量
- 面对强壮僵尸和BOSS时使用奶息喷射
- 生命值低于30时及时恢复
- 能量满时不要恢复，会浪费
- BOSS战前确保满状态！

## 🔧 故障排除

### 终端不显示颜色？

大多数现代终端都支持ANSI颜色。如果看不到颜色：
- Windows：使用Windows Terminal或PowerShell（而非cmd）
- Mac：使用自带的Terminal.app
- Linux：大部分终端默认支持

### Python版本问题？

检查你的Python版本：
```bash
python --version
```

如果低于3.6，请升级Python。
