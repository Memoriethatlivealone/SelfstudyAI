# 🐉 奶龙大战僵尸 - 图形版游戏

真正的图形界面游戏！可以用鼠标和键盘操作的动作游戏。

## 🎮 游戏截图

- 彩色图形界面
- 可爱的奶龙角色
- 鼠标瞄准射击
- 实时动作战斗
- 7波敌人挑战

## 📋 系统要求

- Python 3.6+
- Pygame库

## 🚀 安装步骤

### 1. 安装Pygame

打开命令提示符（CMD），输入：

```bash
pip install pygame
```

或者：

```bash
python -m pip install pygame
```

### 2. 运行游戏

安装完成后，运行：

```bash
python milkdragon_gui_game.py
```

或者双击 `启动图形游戏.bat` 文件（Windows）

## 🎯 游戏操作

### 键盘控制
- **W / ↑** - 向上移动
- **S / ↓** - 向下移动  
- **A / ←** - 向左移动
- **D / →** - 向右移动
- **空格键 / H** - 恢复生命值（消耗15能量，恢复30 HP）

### 鼠标控制
- **左键点击** - 普通攻击（向鼠标位置发射蓝色能量球）
- **右键点击** - 特殊攻击"奶息喷射"（消耗20能量，发射紫色大能量球）

## 🌟 游戏特色

### 战斗系统
- **实时战斗** - 自由移动，鼠标瞄准射击
- **两种攻击** - 普通攻击（蓝色）和特殊攻击（紫色）
- **能量系统** - 能量自动恢复，技能需要消耗能量
- **生命恢复** - 可以消耗能量恢复生命值

### 敌人类型
- **🟢 普通僵尸**（第1-3波）：速度快但血量少
- **🟠 强壮僵尸**（第4-6波）：血量高，伤害中等
- **🔴 僵尸王BOSS**（第7波）：血量超高，伤害巨大

### 游戏机制
- **7波挑战** - 每波敌人越来越强
- **计分系统** - 击败敌人获得分数
- **波次过渡** - 击败所有敌人进入下一波
- **胜利条件** - 击败第7波的僵尸王

## 💡 游戏技巧

1. **保持移动** - 不要站在原地，躲避僵尸的攻击
2. **能量管理** - 普通敌人用普通攻击，强敌用特殊攻击
3. **及时恢复** - HP低于30时按空格恢复
4. **BOSS战准备** - 第6波结束后确保满血满能量
5. **瞄准优先** - 先攻击最近的敌人

## 🐛 故障排除

### 提示"No module named 'pygame'"

说明Pygame没有安装成功，重新运行：
```bash
pip install pygame
```

### 游戏窗口打不开

确认Python版本是3.6或更高：
```bash
python --version
```

### 游戏卡顿

关闭其他占用资源的程序，游戏需要流畅的60 FPS运行。

## 🎉 开始游戏

1. 确保已安装Pygame
2. 运行游戏
3. 点击"开始游戏"按钮
4. 用WASD移动，鼠标射击！
5. 保卫奶龙的家园！
