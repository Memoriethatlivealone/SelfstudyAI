# 小新大冒险：放学路上

原创平台冒险游戏原型，使用原创占位角色与关卡素材，预留授权资源接口。

## 功能特性

- ✅ **完整的移动系统**：支持 A/D 和左右方向键移动
- ✅ **流畅的物理引擎**：跳跃、冲刺、郊狼时间、跳跃缓冲
- ✅ **独立渲染系统**：支持待机、行走、跳跃、受伤、冲刺动画
- ✅ **多关卡系统**：JSON 格式关卡定义，支持检查点、敌人、道具
- ✅ **完整的 UI**：标题界面、暂停、游戏结束、胜利界面
- ✅ **资源预留接口**：支持通过 `assets/manifest.json` 替换为授权素材

## 快速开始

### 安装依赖

需要 Python 3.11+ 和 Pygame 2：

```bash
pip install -r requirements.txt
```

### 启动游戏

**方式1：双击启动文件（推荐）**
```
启动小新大冒险.bat
```

**方式2：命令行直接进入游戏**
```bash
python -m game.main --play
```

**方式3：从标题界面开始**
```bash
python -m game.main
```

## 操作说明

| 按键 | 功能 |
|------|------|
| **A** 或 **左方向键** | 向左移动 |
| **D** 或 **右方向键** | 向右移动 |
| **Space** | 跳跃 |
| **Shift** | 冲刺 |
| **Esc** | 暂停/继续 |
| **R** | 重新开始当前关卡 |
| **Enter** | 确认/继续 |

## 技术亮点

### 🔧 移动系统修复

**问题**：无法使用 A/D 或左右方向键移动角色

**根本原因**：
- `main.py` 的 `update()` 方法混合使用了事件驱动（`self.held_keys`）和轮询式（`pygame.key.get_pressed()`）两种按键检测方式
- 导致在游戏启动或状态切换时按键状态不一致

**解决方案**：
1. ✅ 统一使用事件驱动的 `self.held_keys` 管理按键状态
2. ✅ 移除 `pygame.key.get_pressed()` 的重复检测
3. ✅ 窗口失焦时清空按键状态和玩家速度
4. ✅ 增加 12 项自动化测试覆盖所有移动场景

### 🎨 渲染系统优化

将角色绘制拆分为独立的 `CharacterRenderer` 类：

- ✅ 支持待机、行走、跳跃、受伤、冲刺动画
- ✅ 角色阴影效果
- ✅ 方向朝向
- ✅ 行走脚步动画（腿部交替摆动）
- ✅ 受伤闪烁效果
- ✅ 冲刺时身体倾斜效果
- ✅ 预留 `AssetRenderer` 接口，支持加载授权精灵图

### 📦 资源管理

使用原创几何模型作为占位角色：
- ✅ 不包含任何《蜡笔小新》版权素材
- ✅ 通过 `assets/manifest.json` 预留资源接口
- ✅ 可在获得授权后替换为正版素材
- ✅ 支持精灵图、动画帧、音频、字体等资源类型

## 已知限制

1. **素材限制**：当前使用原创几何图形作为占位角色，未包含《蜡笔小新》官方素材
2. **音频系统**：音频播放功能已实现但未启用（需要音频文件）
3. **字体回退**：在没有中文字体的系统上，UI 文本可能显示为方框
4. **窗口缩放**：支持窗口缩放，但保持 1280x720 逻辑分辨率
