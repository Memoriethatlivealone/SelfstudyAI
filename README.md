# 🍅 番茄时钟 - Pomodoro Timer

一个简洁美观的番茄工作法计时器，帮助你提高专注力和工作效率。

## 功能特点

### 核心功能
- ⏱️ **三种计时模式**
  - 专注时间（默认25分钟）
  - 短休息（默认5分钟）
  - 长休息（默认15分钟）

- 🎯 **智能提醒**
  - 每4个番茄钟后自动切换到长休息
  - 浏览器通知提醒
  - 可选的提示音

- 📊 **统计追踪**
  - 记录完成的番茄钟数量
  - 数据持久化保存

- ⚙️ **自定义设置**
  - 自定义各模式的时长
  - 自动开始休息开关
  - 提示音开关

### 界面特色
- 🎨 渐变色背景，不同模式不同颜色
- 📱 响应式设计，支持手机和平板
- 💫 流畅的动画效果
- 🌐 完全中文界面

## 使用方法

### 快速开始
1. 用浏览器打开 `index.html` 文件
2. 点击"开始"按钮开始计时
3. 专注工作，直到计时器提醒
4. 休息后继续下一个番茄钟

### 详细说明

#### 开始计时
- 点击**开始**按钮启动计时器
- 计时器运行时，按钮变为**暂停**
- 可随时暂停和恢复

#### 切换模式
- 点击顶部的**专注**、**短休息**、**长休息**按钮切换模式
- 只能在计时器停止时切换模式

#### 重置计时器
- 点击**重置**按钮将当前模式的时间恢复到初始值

#### 自定义设置
1. 在页面底部找到**设置**区域
2. 修改各模式的时长（1-60分钟）
3. 勾选或取消**自动开始休息**（完成专注后自动进入休息）
4. 勾选或取消**启用提醒音**
5. 所有设置自动保存

## 番茄工作法介绍

番茄工作法（Pomodoro Technique）是一种时间管理方法：

1. **选择任务** - 确定要完成的工作
2. **设置番茄钟** - 通常为25分钟
3. **专注工作** - 在这段时间内全神贯注
4. **短暂休息** - 5分钟放松
5. **重复循环** - 每4个番茄钟后休息15-30分钟

### 优点
- ✅ 提高专注力和效率
- ✅ 减少工作疲劳
- ✅ 更好的时间管理
- ✅ 清晰的进度追踪

## 数据存储

所有数据保存在浏览器的 LocalStorage 中，包括：
- 自定义时长设置
- 完成的番茄钟数量
- 偏好设置（自动开始、提示音等）

数据只存储在本地，不会上传到服务器。

## 故障排除

### 通知不显示
- 检查浏览器是否允许通知权限
- 某些浏览器需要 HTTPS 或 localhost

### 声音不播放
- 确保"启用提醒音"已勾选
- 检查系统音量设置
- 某些浏览器需要用户交互后才能播放声音

### 设置不保存
- 检查浏览器是否允许 LocalStorage
- 无痕模式下数据不会持久保存
