# 奶龙大战僵尸

基于 Vite、HTML5 Canvas、JavaScript 和 CSS 的原创卡通路线防守小游戏。所有图形由 Canvas 和 CSS 本地绘制，不依赖远程图片、音效或接口。

## 启动

```powershell
npm install
npm run dev
```

然后访问 `http://127.0.0.1:5173/`。

## 操作

- 点击左侧奶龙卡片，再点击地图格子部署。
- 点击地图中的能量果收集资源。
- `P` 暂停/继续，`R` 重新开始，`Escape` 取消部署；游戏区域右键也可取消。
- 顶部音符按钮可以切换 Web Audio 提示音。

## 玩法

地图有 5 条路线、每条 9 个格子。普通奶龙负责攻击，冰霜奶龙负责减速，火焰奶龙负责范围伤害，坚果奶龙负责阻挡。完成 10 波即可胜利，僵尸抵达左侧则失败。
