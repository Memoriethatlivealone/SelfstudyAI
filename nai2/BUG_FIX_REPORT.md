# Bug修复报告

## 已修复的Bug

### 1. ✅ InputHandler渲染冲突 (关键bug)
**问题**: `drawPlacementPreview()`在鼠标移动事件中直接绘制到canvas，与主渲染循环冲突
**修复**: 将预览绘制移到Renderer的render()方法中，通过`getPlacementPreview()`获取预览信息

### 2. ✅ 资源精度问题
**问题**: 资源加减可能产生浮点数
**修复**: 使用`Math.floor()`确保资源始终为整数

### 3. ✅ Canvas最小尺寸验证
**问题**: 窗口过小时canvas尺寸可能为0
**修复**: 设置最小尺寸800x450

### 4. ✅ 网格计算安全性
**问题**: 可用空间可能为负数
**修复**: 使用`Math.max()`确保最小值

### 5. ✅ 初始资源不足
**问题**: 100阳光不足以快速部署角色
**修复**: 增加到150阳光

### 6. ✅ 僵尸生成延迟
**问题**: 第一个僵尸出现太慢
**修复**: 初始化时减去2秒，让僵尸更快出现

### 7. ✅ 波次间隔太长
**问题**: 15秒等待太久
**修复**: 改为8秒

### 8. ✅ Renderer和InputHandler连接
**问题**: Renderer无法访问InputHandler的预览信息
**修复**: 在main.js中建立双向连接
