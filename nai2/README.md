# 🐉 奶龙大战僵尸 🧟

一个使用 HTML5 Canvas 和 JavaScript 开发的原创塔防小游戏。

## 游戏简介

僵尸大军正在入侵！部署你的奶龙战士来保卫家园！这是一个类似塔防玩法的策略游戏，玩家需要在5条战斗路线上合理部署不同类型的奶龙角色，阻止僵尸到达地图左侧。

## 技术栈

- **前端框架**: 纯 HTML5 + CSS3 + JavaScript (ES6+)
- **构建工具**: Vite 5.0
- **渲染技术**: Canvas 2D API
- **音效系统**: Web Audio API

## 游戏特性

### 四种奶龙战士

1. **普通奶龙** (💰 100)
   - 蓝色圆形龙
   - 发射普通攻击
   - 平衡的攻击力和生命值

2. **冰霜奶龙** (💰 150)
   - 青色菱形龙
   - 发射冰冻弹，减慢僵尸速度
   - 适合配合其他角色使用

3. **火焰奶龙** (💰 175)
   - 红色三角形龙
   - 发射火球，造成范围伤害
   - 高伤害，适合对付成群僵尸

4. **坚果奶龙** (💰 50)
   - 棕色方形龙
   - 高生命值，阻挡僵尸前进
   - 不攻击但能抗伤害

### 四种僵尸类型

1. **普通僵尸** - 绿色，基础属性
2. **快速僵尸** - 粉色，移动速度快
3. **防御僵尸** - 灰色，高生命值
4. **巨型僵尸** - 紫色，血厚攻击高

### 游戏机制

- **资源系统**: 通过收集阳光获得资源，用于部署奶龙
- **波次系统**: 共10波僵尸进攻，难度逐渐增加
- **冷却系统**: 每个角色放置后有冷却时间
- **网格系统**: 5行9列的战斗地图
- **特殊效果**: 冰冻减速、火焰溅射

## 操作方式

### 鼠标操作

- **左键点击角色卡片**: 选择要部署的奶龙
- **左键点击地图格子**: 在该位置部署选中的奶龙
- **左键点击阳光图标**: 收集资源
- **右键**: 取消当前选择

### 键盘快捷键

- **P键**: 暂停/继续游戏
- **R键**: 重新开始游戏
- **Esc键**: 取消当前选择

### 游戏界面

- **顶部状态栏**: 显示当前资源、波次和击败数量
- **左侧卡片栏**: 显示可用的奶龙角色及其费用
- **中央游戏区**: 战斗地图，部署角色和观察战斗
- **控制按钮**: 暂停、重新开始、音效开关

## 游戏目标

- **胜利条件**: 成功防御10波僵尸进攻
- **失败条件**: 任何僵尸到达地图最左侧

## 策略提示

1. 优先收集阳光资源，保持资源充足
2. 在前排放置坚果奶龙阻挡僵尸
3. 在后排放置攻击型奶龙输出伤害
4. 冰霜奶龙减速配合火焰奶龙范围伤害效果好
5. 注意观察不同路线的僵尸数量，合理分配防御力量
6. 快速僵尸需要提前布防
7. 防御僵尸和巨型僵尸需要集火攻击

## 开发说明

### 代码结构

游戏采用面向对象设计，主要类包括：

- `GameState`: 管理游戏状态、逻辑更新、碰撞检测
- `Renderer`: 负责所有绘制操作
- `InputHandler`: 处理鼠标和键盘输入
- `Character`: 角色实体类
- `Zombie`: 僵尸实体类
- `Bullet`: 子弹实体类
- `SunResource`: 资源实体类
- `AudioManager`: 音效管理

### 游戏循环

使用 `requestAnimationFrame` 实现平滑的游戏循环：

```javascript
function gameLoop() {
  if (!gameState.isPaused) {
    gameState.update();  // 更新游戏逻辑
    updateUI();          // 更新UI显示
  }
  renderer.render();     // 渲染画面
  requestAnimationFrame(gameLoop);
}
```

### 碰撞检测

- 子弹与僵尸：基于行和距离判断
- 僵尸与角色：基于行和距离判断

### 性能优化

- 及时移除死亡对象
- 子弹超出屏幕自动销毁
- 过期阳光自动移除
- 使用对象池减少GC压力（可选改进）
